⚡ Global Search

Data comes only from: Delivery Status file → Sheet 1 and Order Status file → Order Status sheet. Search by PI, GD, Color or Construction. Press + to add more search boxes (any number of PI, colors...). Same type = "or" (PI 15300 or PI 15302); different types = "and" (those PIs and Black). Then use the ▼ filter in the table header to keep only the colors / values you need.
